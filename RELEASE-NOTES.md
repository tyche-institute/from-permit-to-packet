# From Permit to Packet v0.1.0

Initial public research release, 13 August 2026.

Archival DOI: <https://doi.org/10.5281/zenodo.21923744>

## Included evidence

- a matched replay corpus with 21 positive/negative pairs and one clean
  baseline;
- five verifier treatments with 22/22 authorised controls accepted;
- 21 designed faults and a 448-case deterministic mutation sweep;
- a prospective, precommitted eight-measurement RIPE Atlas trace;
- 32/32 scheduled result rows and 848 observed credits under a 1,060-credit
  ceiling;
- signed Permit, Closure, witness, privacy-minimised capture manifest, and
  SHA-256 manifests;
- Python reference implementation, unit tests, performance snapshot, full
  manuscript, claim–evidence matrix, and release metadata;
- a GitHub-hosted prospective verifier that checks both checkout and production
  artifacts.

## Evidence boundary

This release is a research profile, not a SCITT or RATS conformance claim, RIPE
signature, independent audit, production assurance service, legal-compliance
determination, or global-availability measurement. The witness is logically
separate but shares Tyche administration and the RIPE upstream.

## Privacy boundary

No API credential, private key, PEM file, or raw address-bearing RIPE result
row is included. The private raw capture remains on Zeus1; its public manifest
contains privacy-minimised filenames, sizes, and SHA-256 digests.
